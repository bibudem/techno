# Processing Community Day - Montréal 2026

Site web one-page pour le Processing Community Day (PCD_MTL26), organisé
à l'Université de Montréal (Campus MIL) le 24 octobre 2026.

Aucune installation ni build n'est nécessaire : c'est du HTML/CSS/JS statique.
p5.js et les polices (Figtree, JetBrains Mono) sont chargés depuis des CDN.
